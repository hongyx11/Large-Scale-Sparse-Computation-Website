# Reading Guide

## Learning Path

Read the chapters in order if this is your first pass through sparse
computation. The notation and examples build from storage formats to matrix
operations and then to iterative solvers.

## What to Focus On

For each chapter, track three quantities:

- the data structures used to store the problem
- the memory traffic required by the main operation
- the numerical or performance bottleneck that controls scaling

## When to Run Code

Run the notebook chapters when you want to change problem sizes, matrix
structure, or solver tolerances. The printed outputs are small enough to make
experiments quick.
